# 论文-代码公式不一致编目

学术代码审查中常见的论文正文与代码实现不一致模式。**处理原则：代码为根本依据（代码产生实际实验数字），修正论文文字。**

## 类型 1：维度/索引公式中的符号混淆

**常见表现：** 论文公式中行列维度、通道数、分块数的行列关系与代码不符。代入实际配置验算时论文公式的结果与代码输出不同。
**修正：** 逐组代入实际维度，将论文公式更正为与代码一致。

## 类型 2：填充/边界处理规则

**常见表现：** 论文描述的填充方式在特定配置下导致负填充量或维度不可能。代码使用了 max/min/条件处理。
**修正：** 重写为与代码逻辑一致的描述。

## 类型 3：激活函数与归一化层

**常见表现：** 论文写 ReLU 但代码用 LeakyReLU/GELU；论文写 BatchNorm 但代码用 LayerNorm；论文写 affine=True 但代码为 False。影响特征分布和训练动态。
**修正：** 检查 `__init__` 和 `forward` 中的实际调用，更新论文描述。

## 类型 4：损失函数与正则化

**常见表现：** 论文公式缺归一化分母（如除以 teacher norm），或漏写正则化项（如 weight decay 在 optimizer 中而非 loss 中），或损失权重与论文声称不一致。
**修正：** 阅读 loss 函数和 optimizer 配置的完整代码，在论文中补充所有项。

## 类型 5：超参数遗漏或写错

**常见表现：** 论文声明使用某个参数值（如 dropout=0.1, epsilon=1e-5），代码使用不同值。或论文使用了某个符号参数但未给出具体数值。
**修正：** 读取 argparse 默认值或 config，更新论文。

## 类型 6：优化器与训练配置

**常见表现：** 论文写 Adam 但代码用 AdamW（有 decoupled weight decay），或 betas/epsilon 不同，或实际有 learning rate scheduling 但论文声称 constant lr。
**修正：** 读取 optimizer 初始化和 scheduler 配置的完整参数。

## 类型 7：数据预处理与增强

**常见表现：** 论文描述的归一化统计量（mean/std）与实际代码中的值不同；数据增强参数（如 random crop scale、rotation degree）论文描述比代码更激进或更保守。验证集做了训练增强。
**修正：** 读取 transforms 代码，记录确切参数。

---

**通用检测流程：**
1. 对论文中每个关键公式和超参数声明，在代码中找到对应位置
2. 代入具体数值手算或运行代码验证
3. 对比：一致通过，不一致记录差异
4. **代码产出数字 → 改论文；代码确有 bug → 最小修复 + 测试锁死**
